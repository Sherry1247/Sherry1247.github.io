BadgerPlan (UW–Madison Academic Planning)

A degree-planning web app for UW–Madison students: build a semester-by-semester plan, see which courses count twice for a double major, and check every choice against prerequisites, grades, and offering history.

Degree planningPrerequisite checksCourse dataWeb app

Covers the 2026–27 UW–Madison catalog: 8,982 courses and 262 majors and named options, with grade history for 8,536 courses and instructor ratings for 2,195 instructors.

Key Features

  • Fills each term with required courses, prerequisites, and Gen Ed, schedules shared courses first, and keeps terms under a credit limit.
  • Drag courses between terms; every move is re-checked for prerequisites, usual offering season, and credit load.
  • DARS-style requirements check and double-major comparison; plans can be saved, exported, or printed for an advisor.
  • Campus map showing where scheduled classes meet, by building and time of day.

2026 · Interactive story

Titanic Time Travel (The Last Crossing)

A scroll-driven, bilingual (中文 / EN) web story that zooms from a world map to the Titanic wreck 3,840 m below the surface, then follows a passenger’s story.

Interactive storytellingScroll animationBilingual UIWeb app

The experience moves through four stages: zooming in on a map, descending with a diver, exploring the wreck, and following one passenger’s story.

Key Features

  • Map zoom with marked locations that leads into the descent.
  • Live depth counter that follows the scroll down to the wreck at 3,840 m.
  • Passenger-focused narrative layered over the wreck exploration.
  • Language toggle between Chinese and English, plus a reset control.

MediMenu (AI Meal Planner)

Designed and built an AI-assisted meal planner and personalization engine during the CheeseHacks 2026 hackathon, leading a 4-person development team.

React FastAPI GPT-4o Python REST APIs UI/UX Design

Integrated large language models (LLMs) with dietary databases to deliver customized nutritional recommendations based on user health parameters. Built backend using FastAPI and structured responsive frontend in React, creating an interactive portal that auto-generates grocery lists and meal plans.

Key Features & Contributions

  • Integrated GPT-4o API for personalized, context-aware recipe recommendations.
  • Developed a FastAPI backend with asynchronous query handling for rapid response times.
  • Constructed a React-based frontend dashboard with visual recipe cards and nutritional breakdowns.
